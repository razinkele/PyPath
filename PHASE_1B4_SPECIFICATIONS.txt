================================================================================

Location: Line 216-333 (118 lines)
Type: @dataclass

Attributes:
  source_group: str
    Name of group being discarded (e.g., "Cod", "Juvenile herring")

  target_group: str | None = None
    Group that receives discards (for predation fate)
    None for lost/detritus/benthos fates
    Must be specified if fate='predation'

  discard_rate: float = 0.0
    Proportion of source_group catch that is discarded (0-1)
    Example: 0.15 = 15% discarded, 85% landed
    Constraint: 0.0 <= discard_rate <= 1.0

  fate: str = "lost"
    Where discards go after being removed from landed catch
    Valid values: 'lost', 'predation', 'detritus', 'benthos'
    
    Fate meanings:
      'lost'      - Total mortality, biomass removed from system
      'predation' - Routed to target_group as available prey
      'detritus'  - Enters detritus pool (organic matter)
      'benthos'   - Enters benthic organic matter pool

  depth_dependent: bool = False
    If True, fate depends on depth/spatial location (Ecospace)
    Used for spatially-explicit discard routing
    False: uniform routing across all patches

Validation (__post_init__):
  1. discard_rate in [0.0, 1.0]
  2. fate in ('lost', 'predation', 'detritus', 'benthos')
  3. If fate='predation', target_group must not be None

Methods:
  is_valid() -> bool
    Checks: source_group exists, discard_rate in [0,1], fate valid
    If fate='predation', checks target_group exists
    Returns: True if valid, False otherwise

  apply_to_biomass(biomass: float) -> float
    Calculates actual discard biomass from total catch
    Formula: discard_biomass = biomass * discard_rate
    Example: 100t * 0.15 = 15t discarded

  to_dict() -> dict
    Serializes path to dictionary
    Keys: source_group, target_group, discard_rate, fate, depth_dependent

  from_dict(data: dict) -> DiscardPath @classmethod
    Reconstructs path from dictionary
    Handles optional fields (target_group=None, etc.)

Example:

allocate_catch(total_catch: float, catchability: dict) -> dict[str, float]
  Location: Line 436-479 (44 lines)
  
  Purpose: Distribute total catch proportionally across groups
  
  Parameters:
    total_catch: float
      Total biomass caught by fleet (tons)
    catchability: dict[str, float]
      q values: {group_name -> q (0-1)}
  
  Returns: dict[str, float]
    {group_name -> catch_biomass}
  
  Logic:
    1. Normalize q values: q_i / sum(q)
    2. Allocate: catch_i = total_catch * (q_i / sum(q))
  
  Example:
    >>> allocate_catch(100.0, {"Cod": 0.7, "Haddock": 0.3})
    {"Cod": 70.0, "Haddock": 30.0}
