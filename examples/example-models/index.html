    Example Models¶

    PyPath ships three real food-web models, from EPath's EwE-F test cases, ready to balance and run. In the app, pick one from Open a real model… on the Home page; its EwE-F Ecosim settings then become the starting scenario on the Ecosim page.

    Name Model Groups Source
    Central_Baltic Baltic Proper, 1974, modified for a stationary baseline 22 Tomczak et al. (2012), Ecological Modelling 230, 123–147
    Curonian_Lagoon Curonian Lagoon pelagic food web, 2005–2007 19 Marine Research Institute, Klaipėda University
    Lithuanian_Coast Exposed sandy coast of Lithuania, with round goby 44 Razinkovas-Baziukas et al. (2017), Estuarine, Coastal and Shelf Science 195, 110–123

    Each model's folder (pypath/examples/data/<name>/) has a README with its source, the changes made to it and the files included: the EwE-F Ecopath inputs and the Ecosim settings (vulnerabilities, group settings, fishing forcing). PyPath's balance of each matches Ecopath-F's.

    Balance and run one¶

    from pypath.core.ecopath import rpath
from pypath.core.ecosim import rsim_run
from pypath.examples import example_ecosim_scenario, load_example_model

params = load_example_model("Lithuanian_Coast")
balanced = rpath(params)

years = range(1, 11)
scenario = example_ecosim_scenario("Lithuanian_Coast", years=years)
result = rsim_run(scenario, method="RK4", years=years)

class ExampleModel:
    """An example model: its name, what it is and where it comes from.

    Attributes
    ----------
    name : str
        The name to load it by, also its folder in ``pypath/examples/data``.
    title : str
        A short title.
    description : str
        The food web, its groups and the changes made to the source model.
    source : str
        The publication or institution the model comes from.
    """

    name: str
    title: str
    description: str
    source: str

    @property
    def path(self) -> Path:
        """The model's folder."""
        return DATA / self.name

    @property
    def ecopath_path(self) -> Path:
        """The EwE-F Ecopath inputs (folder with the ``filenames.nml``)."""
        return self.path / "ecopath"

    @property
    def ecosim_path(self) -> Path:
        """The EwE-F Ecosim inputs (folder with the ``filenames.nml``)."""
        return self.path / "ecosim"

    def example_ecosim_scenario(
    name: str,
    years: Optional[range] = None,
    fast_group_rule: Optional[str] = None,
) -> "RsimScenario":
    """An Ecosim scenario with the example's own Ecosim settings.

    Parameters
    ----------
    name : str
        An example's name (see :func:`list_example_models`).
    years : range, optional
        Simulation years; the default is the model's EwE-F run length.
    fast_group_rule : str, optional
        Passed to :func:`pypath.core.ecosim.rsim_scenario`.

    Returns
    -------
    RsimScenario
        From :func:`pypath.io.ewef.ecosim_scenario_from_ewef`: the balanced
        model with the example's vulnerabilities, group settings and fishing.
    """
    from pypath.io.ewef import ecosim_scenario_from_ewef

    model = example_model(name)
    return ecosim_scenario_from_ewef(
        model.ecopath_path,
        model.ecosim_path,
        years=years,
        fast_group_rule=fast_group_rule,
    )

    def example_model(name: str) -> ExampleModel:
    """The example model of that name (case does not matter).

    Raises
    ------
    ValueError
        If there is no example of that name; the message lists the names.
    """
    wanted = str(name).strip().lower()
    for model in _CATALOG:
        if model.name.lower() == wanted:
            return model
    names = ", ".join(m.name for m in _CATALOG)
    raise ValueError(f"No example model {name!r}; the examples are: {names}")
