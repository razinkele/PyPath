# Rpath Reference Data for PyPath Validation

This directory contains reference data extracted from the Rpath R package.

## Source
- Package: Rpath
- Repository: https://github.com/NOAA-EDAB/Rpath
- Model: REcosystem (standard test model)

## Contents

### ecopath/
- `model_params.csv`: Input model parameters
- `diet_matrix.csv`: Diet composition matrix
- `balanced_model.json`: Complete balanced model output
- `balanced_output.csv`: Key balanced parameters (B, PB, QB, EE, GE, M0, TL)
- `dc_matrix.csv`: Diet composition matrix (balanced)

### ecosim/
- `ecosim_params.json`: Ecosim simulation parameters
- `biomass_trajectory_rk4.csv`: 100-year simulation with RK4
- `biomass_trajectory_ab.csv`: 100-year simulation with Adams-Bashforth
- `catch_trajectory_rk4.csv`: Catch outputs
- `biomass_doubled_fishing.csv`, `biomass_doubled_fishing_ab.csv`: 50 years,
  fishing effort x2 for every fleet (RK4 / Adams-Bashforth)
- `biomass_zero_fishing.csv`, `biomass_zero_fishing_ab.csv`: 50 years, no
  fishing (RK4 / Adams-Bashforth)

The baseline trajectories stay at equilibrium (flat to ~5e-5), so only the
fishing scenarios exercise the dynamics.
