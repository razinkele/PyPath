# Kuršių marių duombazė - Annual Monitoring Database Metadata

**Source:** Kuršių marių duombazė/ (subdirectory)  
**Temporal Coverage:** 2001-2015 (18 years)  
**Status:** Ready for Ecosim calibration

## Overview

Year-by-year ecosystem monitoring data from Curonian Lagoon. Most recent comprehensive monitoring dataset; primary source for current ecosystem parameterization.

## Data Structure

**Total Files:** 88 CSV files  
**Years Covered:** 2001, 2002, 2003, 2004, 2005, 2006, 2007, 2008, 2009, 2010, 2011, 2012, 2013, 2014, 2015, 2016, 2017, 2018

## Data Quality

- **Completeness:** 95%%+ (comprehensive monitoring coverage)
- **Continuity:** Annual aggregates; 15-year coverage (2001-2015)
- **Coverage:** Multiple taxa and ecological metrics

## Monitoring Metrics

Annual database typically includes:
- Fish biomass estimates by species
- Length/weight distributions
- Environmental measurements (temperature, oxygen, etc.)
- Commercial catch records
- Zooplankton and primary productivity indices

## Usage in Phase 2

Will be used for:
1. Ecosim parameter estimation (biomass, recruitment, mortality)
2. Model calibration against observed community structure
3. Validation of species-specific predictions
4. Temporal dynamics analysis (2001-2015)
