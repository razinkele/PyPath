# Sugavimai K_M - Landings Dataset Metadata

**Source:** Sugavimai K_M 1947-2011.xls  
**Temporal Coverage:** 1947-2011 (64 years)  
**Status:** Historical reference for validation

## Overview

Commercial fishery landings data spanning 64 years. Provides historical context for ecosystem changes and long-term model validation.

## Data Structure

- **Sugavimai sheet:** 78 observations x 73 columns
  - Primary landings records by species and year
- **Value sheet:** 67 observations x 51 columns
  - Economic value of landings
- **LT Graph sheet:** 66 observations x 10 columns
  - Preprocessed Lithuanian data
- **RUS Graph sheet:** 65 observations x 10 columns
  - Preprocessed Russian sector data

## Data Quality

- **Completeness:** 90-95%% (some years/species may be incomplete)
- **Continuity:** 64-year continuous record (1947-2011)
- **Resolution:** Annual aggregates

## Validation Notes

- Longest available time series for Curonian ecosystem
- Captures major fishery and ecosystem transitions
- Useful for regime shift analysis

## Usage in Phase 2

Will be used for:
1. Long-term ecosystem trend validation (1947-2011)
2. Historical parameter estimation
3. Regime shift detection and analysis
