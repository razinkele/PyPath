3. NutrientExcretion Dataclass (animal waste)
   - Attributes: n_excretion_rate, p_excretion_rate, fecal_n_fraction, fecal_p_fraction

   - Excretion rate scaling: 0-50% for N, 0-20% for P
   - Fecal fractions: 0-1 (proportional split)

4. NutrientUptake Dataclass (producer kinetics)
   - Attributes: n_uptake_rate, p_uptake_rate, half_saturation_n/p
   - Method: calculate_uptake(nutrient_level, rate) → float
   - Monod equation: v = (Vmax * [S]) / (Km + [S])
   - Tested at 1-20 mg/L nutrient levels (works correctly)

5. NutrientCycle Container Class (full ecosystem)
   - Three dictionaries: contents, excretions, uptakes
   - Methods:
     * add_content/excretion/uptake() - Add group parameters
     * validate() → (bool, List[str]) - Consistency checks
     * calculate_mass_balance(rpath_params) - N/P/C totals
     * to_dataframe() - Export to pandas
     * from_dataframe(@classmethod) - Import with error handling
   - Tested: 4-group ecosystem lossless roundtrip

6. Module Functions
   - validate_nutrient_cycle(cycle) - Full validation wrapper
   - estimate_excretion_from_pb(pb_ratio, group_type) - Heuristic estimation
     * Supports: consumer, producer, detritus
     * PB-based scaling for consumers (tested: PB=0.5 → 15% N excretion)

USAGE EXAMPLE
-------------
from pypath.core.nutrients import *

# Create components
content = NutrientContent("Fish", 11.0, 1.5, 47.0, 8.0)
excretion = NutrientExcretion("Fish", 12.0, 2.0, 0.4, 0.6)
uptake = NutrientUptake("Phytoplankton", 0.8, 0.15, 8.0, 1.0)

# Build ecosystem
cycle = NutrientCycle()
cycle.add_content(content)
cycle.add_excretion(excretion)
cycle.add_uptake(uptake)

# Validate
is_valid, msgs = cycle.validate()

# Export/calculate
df = cycle.to_dataframe()
balance = cycle.calculate_mass_balance(rpath_params)
