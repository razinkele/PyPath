## Configuration Specifications

### Calibration Setup

**Objective Function**:
- Minimize: Σ w_i × (pred_i - obs_i)² 
- Success: SSR < 50, R² > 0.70

**Parameters** (60 total):
- Ecotrophic Efficiency (EE): 30 parameters, range 0.5-1.0
- Vulnerability (VV): 30 parameters, range 0.5-10.0

1. **Validate Setup** (1 minute):
   ```bash
   python validate_pest_setup.py
   ```
   Expected: "✓ All PEST files valid and ready for calibration!"

2. **Review Documentation** (15 minutes):
   ```bash

   # Quick reference  
   cat PEST_CALIBRATION_CONFIGURATION_SUMMARY.md
   ```

3. **Run Calibration** (4-8 hours):
   ```bash
   # Install PEST first (see guide)
   python run_pest_calibration.py
   
   # Or directly with PEST++
   pestpp-ies curonian_pest.pst --n_threads 4
   ```

4. **Review Results** (30 minutes):
   - Check `curonian_pest.rec` for convergence history
   - Review `fitted_parameters.csv` for best-fit values
   - Analyze `curonian_pest.par` for parameter uncertainty

### For Integration

```python
# Use the PEST framework with PyPath
from pypath.core.pest_calibration import PestCalibrator

calibrator = PestCalibrator(model, params)
result = calibrator.calibrate(scenario_factory, method="glm")

# Export results
calibrator.export_results("calibration_results/")
```
